安装目录：
游戏文件夹\content\tracks

如：D:\assettocorsa\content\tracks

Steam安装特别注意，安装目录为：Steam库文件夹的steamapps\common\assettocorsa\content\tracks

Installation:

Inside Assetto Corsa installation folder, the is a track folder in content folder, unzip the fugang_sari folder here.

Example:
D:\assettocorsa\content\tracks

Tips for standard Steam installation:
Game folder should be inside SteamLibary steamapps\common\assettocorsa\
