# 电控模拟结果与可用范围

日期：2026-10-10。运行LuaJIT 2.1/Lupa 2.6，共用su7_control.lua。原mod未修改。以下是简化平面车辆上的数值试验，不是AC遥测或厂家标定。当前量产mod的空悬/绞牙归属未确认；Street/Sport/Track仅为电控模式，平面模型没有悬架动态，结果不能作为两种底盘的性能对照。

30项核心检查（含700组混合输入）与13项模拟CSP接线检查通过；6个场景各比较固定分配参考与实验控制，均无非有限状态或退出前进行驶域。结果文件中的控制核心及配置SHA256与当前文件一致，原mod源数据SHA256与观测包构建前一致。

ESC/TC/TVC 为独立整数：ESC 0–4、TC 0–8 越大干预越强；TVC 0–3 越大干预越少。零档不关闭。默认 ESC4/TC8/TVC0 保持之前整套实验行为，以下六场景默认数值与旧版一致。这不是已测得的原厂档位响应，也不代表圈速单调变化。

## 整套控制对照

参考采用同一平面车辆和原MAP_1动力曲线，固定前22/后78、简化TC/ABS及原coast；实验同时改变电门请求、功率倍率、各轮TC、横摆控制和回收。因此不能将全部差异归因于后轮扭矩矢量。

- **出弯加电门**：侧滑峰值 4.24° → 3.77°；滑移绝对峰值 0.495 → 0.276；场景结束车速 169.8 → 168.5 km/h。
- **低附着出弯**：侧滑峰值 9.84° → 3.39°；滑移绝对峰值 0.775 → 0.318；场景结束车速 113.1 → 108.4 km/h。
- **横摆/侧滑扰动**：侧滑峰值 2.99° → 2.90°；滑移绝对峰值 0.025 → 0.037；场景结束车速 96.0 → 78.0 km/h。
- **分级制动**：侧滑峰值 0.00° → 0.00°；滑移绝对峰值 0.144 → 0.209；场景结束车速 0.0 → 0.0 km/h。
- **99.5% SOC制动**：侧滑峰值 0.00° → 0.00°；滑移绝对峰值 0.061 → 0.063；场景结束车速 20.7 → 23.3 km/h。
- **驾驶模式切换**：侧滑峰值 3.74° → 3.64°；滑移绝对峰值 0.367 → 0.169；场景结束车速 197.7 → 176.9 km/h。

低附着场景改善较大，但实验输出功率更低、结束车速也略低，电门和TC限制占了很大作用。不能据此承诺实车侧滑也同比下降。

分级制动中，实验模型回收能量约0.208 kWh，但滑移峰值比参考高（0.209对0.144）。因此混合制动结构已经可测，控制增益和踏板映射仍有校准空间。接近满电时回收降低，摩擦制动承担更多请求；机械扭矩有限，不能无限补足最大踏板需求。

## 单独开关横摆反馈

同一实验电门、动力和TC参数，只关闭横摆目标对应的差动分配与ESC制动。各轮TC及载荷限扭仍可能使左右扭矩不完全相等。

低附着出弯侧滑峰值由 4.86° 降至 3.39°，结束车速为 109.1 / 108.4 km/h；相对共同几何横摆参考的RMS误差由 0.044 增至 0.059 rad/s。这个几何参考没有包含附着和转向不足约束，不能当成真实路径误差。当前整定更重视减小侧滑，转向跟随也更保守。
